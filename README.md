
# 🧾 Sales Performance Dashboard

This project focuses on analyzing sales performance by transforming raw sales data into meaningful business insights using Microsoft Excel. It features an interactive dashboard built with PivotTables, PivotCharts, slicers, and timelines to track key performance indicators such as revenue, total orders, quantity sold, and average order value, while exploring sales trends, regional performance, product categories, sales channels, and top-performing products to support data-driven decision-making.
